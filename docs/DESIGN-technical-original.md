# mem_snapshot 详细设计

状态：第一版实现依据。目标是 Linux/glibc、动态链接程序、启动时 LD_PRELOAD；先保障分配语义与可解释结果，再测量开销。2026-10-25。

## 1. 目标与证据边界

记录通过拦截入口完成的存活堆分配：地址、请求字节数、记录编号、最近一次成功分配/重分配的调用栈。用户发 SIGUSR2 后输出快照。快照中的存活对象不自动认定为泄漏；通过业务生命周期及多次快照的增长分析判断。

不实现越界检测、重复释放保护、悬空指针检测，也不改变应用的分配器。无法捕获绕过动态符号入口的内部调用、私有堆、直接 mmap、静态链接及安全执行模式忽略的 LD_PRELOAD。其他分配器/多个 malloc 拦截库的叠加暂不列入验证范围。程序自身在信号处理函数里调用 malloc 本来就不安全，本工具不使它变得安全。

## 2. 拦截方式

导出 malloc/free/calloc/realloc 以及 aligned_alloc/posix_memalign/memalign/valloc/pvalloc。同名 ELF 符号通过 LD_PRELOAD 优先解析到本库。pthread_once 初始化真实函数指针，dlsym(RTLD_NEXT, name) 查找后续实现。RTLD_NEXT 指的是后续符号，并不保证在任意预加载组合下都是 glibc。

不用历史 __malloc_hook；不依赖 glibc 私有 __libc_malloc。初始化 dlsym 可能递归进入分配入口，因此使用静态、对齐的有界引导区（1 MiB）为解析期间的递归分配服务。引导区采用原子递增分配，free 无操作；realloc 搬迁并保留内容。耗尽返回 ENOMEM。其他线程等待一次初始化完成，不能读取半初始化的函数指针。引导占用在快照中报告。

线程局部递归深度使用 initial-exec TLS。真实分配器调用、堆栈采集、记录操作均在递归保护内。内部递归分配交给真实分配器、不进入追踪表。解析必需符号失败时用 write 输出固定错误并终止，避免继续调用空函数指针。

## 3. 按地址查找：哈希桶中的短链表

| 方案 | 查找/删除 | 高频调用下的主要问题 |
|---|---|---|
| 单链表或双向链表 | O(N) 查找；双向链表只有已知节点时删除才是 O(1) | free 只有指针，仍需遍历 |
| 平衡树 | O(log N) | 每次操作需要比较、旋转及同步 |
| 分片哈希表 | 平均 O(1)，最坏 O(N) | 需要控制装载、冲突与锁竞争 |

选择 64 个分片，每片 1024 个桶（共 65536 桶）。指针经过整数混合散列，低位选择分片，后续位选择桶，不直接使用对齐指针的低位。桶内单链表以指针相等判定命中。每片独立 mutex、节点空闲链表及统计计数。不存在每次调用都必须获取的全局表锁或全局编号计数器。

默认每片最多 4096 个节点（总容量 262144），平均装载约 4；这是容量上限而非已分配空间。节点池每次 mmap 256 个节点，节点随 free 回到所属分片，映射保留到进程结束。达到容量或 mmap 失败时，应用的成功分配仍成功，但增加 dropped 累计计数。分片分布不均可能提前丢记录，输出不能宣称完整。该指标是累计漏记事件，不是当前遗漏对象数。

节点保存 ptr、size、id、depth、最多 32 层原始返回地址和 next。默认采集 16 层，MS_DEPTH=0 可单独测量记账成本。固定节点大小避免热路径再申请栈存储；第一版不引入栈去重、采样、无锁表或在线扩容，避免多个共享索引和回收协议。每个分片自己的递增序号加分片编号构成记录 ID。

## 4. malloc / free / realloc 顺序

malloc/calloc：进入递归保护 → 调真实函数 → 成功后在锁外采集栈 → 持对应分片锁插入 → 返回。失败不插入。真实函数的 errno 必须跨追踪逻辑保留。

free：NULL 直接无操作；引导指针不交给 glibc；普通指针先持分片锁摘除节点并回收到池，再调真实 free。先摘除可防止该地址被另一个线程再次分配后，旧 free 删除新记录。未找到记录仍按原语义交给真实 free；不是重复释放诊断器。保留调用前 errno。

realloc：先摘下旧节点但不回收 → 调真实 realloc → 成功时回收旧节点、记录新地址/大小/新调用栈 → 非零大小失败时将原节点原样放回，保留原 ID/栈/大小。glibc 的 realloc(p,0) 释放 p；返回非 NULL 时记录新对象，NULL 时不恢复旧记录。realloc(NULL,n) 按分配处理。失败、原地扩大、搬迁、零大小都必须验证。真实 realloc 期间不持表锁，避免其内部调用导致锁重入。

calloc 溢出由真实函数处理；引导路径自行检查乘法溢出。posix_memalign 的返回码、输出指针失败时不改写、errno 不改写；对齐接口直接转发对应真实函数，保留其行为。malloc_usable_size 对真实 glibc 指针直接转发，对引导指针返回引导区记录大小。free_sized/free_aligned_sized/cfree 兼容入口经本库 free 路径处理，不读取传入指针所指对象内容。

## 5. 信号与快照

构造函数完成解析、预热 backtrace、创建管道/输出文件/工作线程后才启用追踪。默认使用 SIGUSR2；若此前已有非默认处理方式，拒绝占用并禁用追踪，打印明确错误。后续应用自行改写信号处理方式不受本库管理。

信号处理函数仅保存 errno、向非阻塞管道 write 一个字节、恢复 errno。管道满时允许合并通知；普通信号本身也可能合并，不承诺一信号一快照。不得在 handler 中遍历哈希表、malloc、backtrace、printf 或锁 mutex。

工作线程永久启用递归保护，阻塞等待管道。收到通知后用 mmap 预留最多容量大小的复制缓冲区，再按固定顺序锁住全部分片，将记录和统计复制进去，逆序解锁。输出和符号查询均在解锁后进行。文件写得慢不延长表锁持有时间，但复制阶段仍会暂停所有追踪表更新，耗时随存活对象数增长。

一致性定义：复制时表内记录的一致切面；不等于进程所有指令的暂停点。malloc 尚未登记或 realloc 已摘下旧记录但仍在执行时，可能暂时不在表中。业务需要精确对账时，应暂停业务分配并等待在途操作结束后发信号。

每次快照包含 BEGIN/END 序号、PID、记录数、请求字节合计、累计 dropped、节点池占用、最大桶链长、引导区使用量；各对象含 ID/地址/大小/原始栈。dladdr 在输出阶段补充模块基址和符号信息，/proc/self/maps 记录地址映射。已卸载模块或映射变化可能使符号解释不完整，原始地址仍保留。END 只在全部输出及刷新成功后出现；输出失败向 stderr 报错。文件为 0600、O_EXCL 新建，避免覆盖已有文件；MS_OUTPUT 可指定尚不存在的路径，默认 /tmp/mem_snapshot.<pid>.log。

## 6. 进程生命周期与限制

构造函数之前/库自身启动中的分配不追踪。只支持启动时预加载，不支持运行中 dlopen/dlclose 本库。第一版不在析构阶段自动输出：用户应在进程仍存活时发信号并等到完整 END。进程退出时由系统回收工作线程、管道和映射，避免退出期的析构顺序及 join 死锁。

fork 子进程通过 atfork 子处理程序关闭继承的追踪描述符并禁用追踪，原分配函数继续可用；父进程继续工作。子进程 exec 后重新初始化。第一版不支持 fork 后未 exec 子进程继续采集，也不支持将 _Fork/vfork 后的业务执行作为追踪场景。fork 处理不锁父进程的表，因为子进程永远不访问继承表。

## 7. 性能与资源预算

稳态成本分解：一次真实分配 + 一次堆栈展开（仅分配/成功重分配）+ 一次分片锁与短桶链访问。free 不采集栈。主要潜在开销可能是 backtrace，而非链表，必须实测。

静态桶数组约 512 KiB（64 位）。节点内存按实际 sizeof(node) × 已映射节点计算；默认 262144 个节点约数十 MiB。快照缓冲会另外占用最多记录容量大小的虚拟地址空间，仅复制页实际触碰。报告实测节点大小及映射占用。深度减少主要降低展开时间，固定节点结构不随深度缩小。

第一版配置：MS_DEPTH=0..32，MS_CAPACITY_PER_SHARD 为 256 的整数倍，范围 256..65536，默认 4096；无效配置报错并禁用追踪。容量扩大也增大快照成本。分片数及桶数先固定，以测量结果决定是否参数化。

## 8. 验收计划

1. 编译开启 Wall/Wextra/Werror，验证导出动态符号及 LD_PRELOAD 实际生效。
2. 稳定测试对象的 malloc/calloc/free、跨线程释放、realloc 成功与失败、NULL/零大小、内容保留、errno、对齐接口。
3. 信号生成完整快照，按已知指针对比释放前后；确认符号可识别测试分配点。
4. 多线程并发分配、释放、重分配时重复请求快照，检查超时/崩溃/结构不一致。
5. 小容量压满后 dropped > 0；分配仍成功，释放后槽位复用；覆盖信号冲突、输出失败及 fork 子进程降级。
6. 基准比较无预加载、MS_DEPTH=0、MS_DEPTH=16；至少单线程/多线程和较大存活集合，报告环境、负载、重复次数、中位数、吞吐和相对开销。数字仅代表该机器和该负载，不代表生产性能或性能上限。
